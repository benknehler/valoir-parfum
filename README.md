# Valoir Parfum

Moderne Luxus-Parfum-Shop-Website für die Marke Valoir Parfum.

## Seiten

- Landingpage
- Über uns
- Shop
- Produktdetailseiten
- Warenkorb mit lokaler Grundlogik
- Newsletter-Anmeldung

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Der Build ist für GitHub Pages unter `/valoir-parfum/` konfiguriert und erzeugt zusätzlich eine `404.html` als SPA-Fallback.
