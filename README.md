# Valoir Parfum

Moderne Luxus-Parfum-Shop-Website für die Marke Valoir Parfum.

## Seiten

- Landingpage
- Über uns
- Shop
- Produktdetailseiten
- Warenkorb mit lokaler Grundlogik
- Newsletter-Anmeldung

## Stack

- Next.js App Router
- Tailwind CSS
- Framer Motion
- Static Export für GitHub Pages

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Der Build ist für GitHub Pages unter `/valoir-parfum/` konfiguriert. Next exportiert nach `out`, danach wird der Export für den bestehenden Pages-Workflow nach `dist` kopiert.
